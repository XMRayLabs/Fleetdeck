# FleetDeck

FleetDeck 是面向几十台乃至更多服务器的自托管运维控制台。它把 SSH、RDP、VNC、代理、批量命令、文件分发和可复用自动化剧本集中在一个 Web 界面中，并使用 Docker Compose 部署。

> FleetDeck 基于 [Heavrnl/nexus-terminal](https://github.com/Heavrnl/nexus-terminal) 进行大幅重构，保留原项目署名与 GPL-3.0 许可证。FleetDeck 不是原项目的官方发行版。

## 能做什么

- 统一管理 SSH、Windows RDP 和 Linux VNC 连接。
- 支持临时输入密码、保存的独立密码、私钥、私钥加口令，以及 SOCKS/SSH 代理。
- 按服务器、标签或任意选择集合批量执行命令，并实时查看每台主机的状态与输出。
- 向多台服务器分发文件；单台服务器也可连续执行多条命令。
- 将命令、文件、变量、执行策略组合为可重复使用的“自动化剧本”，选定目标后直接运行。
- 记录审计日志、连接历史、通知与失败状态。
- 完整 Agent 工作台：选择模型/思考等级、逐轮审批或授权任务、多服务器 SSH 执行、结果复查、监控上下文与敏感信息脱敏。
- 通过 WebAuthn Passkey、TOTP 两步验证、IP 策略和 CAPTCHA 加固登录。

## 安全设计

- 连接密码、私钥、代理凭据、剧本敏感变量及 TOTP 密钥使用 AES-256-GCM 加密后存储。
- 主加密密钥、会话密钥和远程网关服务密钥通过 Docker secrets 文件注入，不写入镜像或 Git。
- 登录后轮换会话 ID；Cookie 使用 `HttpOnly`、`SameSite=Strict`，HTTPS 部署默认启用 `Secure`。
- 登录与 API 均有限流，写操作校验 Origin，远程桌面内部 API 使用恒定时间密钥比较。
- 自定义终端 HTML 先经 DOMPurify 清理；脚本和事件处理器不会执行。
- 容器启用只读根文件系统、`no-new-privileges`、能力删除和非 root Node/Nginx 进程。
- Nginx 设置 CSP、点击劫持防护、MIME 嗅探防护和严格的权限策略。

安全问题请不要提交公开 Issue，处理方式见 [SECURITY.md](./SECURITY.md)。

## 快速部署

要求：Docker Engine 24+、Docker Compose v2，以及一个用于正式环境的 HTTPS 反向代理。

```bash
cp .env.example .env
./scripts/init-secrets.sh
docker compose pull
docker compose up -d --no-build
```

Windows PowerShell：

```powershell
Copy-Item .env.example .env
./scripts/init-secrets.ps1
docker compose pull
docker compose up -d --no-build
```

部署前必须修改 `.env` 中的 `RP_ID`、`RP_ORIGIN` 和 `APP_ORIGIN`。正式环境应保持 `COOKIE_SECURE=true`，并仅通过 HTTPS 暴露 Web 端口。完整说明见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

首次启动后访问 `https://你的域名`，创建至少 12 位的管理员密码，然后建议立即启用 Passkey 或 TOTP。

## 终端复制粘贴

工作区默认“专注终端”：临时收起状态、历史、快捷命令、文件和编辑器面板，点击标签栏的“恢复面板”即可回到原布局。切换不重建 SSH 终端，不删除输出或改写已保存的面板配置。终端操作收在右上角 `⋯` 菜单中，复制/粘贴不弹成功、失败提示或内容确认。未配置背景图片或 HTML 时使用终端主题的实色背景，不再叠加透明灰色蒙版。

终端提供复制、粘贴、全选、回到底部按钮。支持 `Ctrl+V` 直接粘贴，也保留 `Ctrl+Shift+C/V`、`Ctrl+Insert` / `Shift+Insert`；`Ctrl+C` 保留为远端中断，不用于复制。启用右键粘贴设置时，右键有选区就复制、无选区则粘贴；`Shift+右键` 保留浏览器菜单。鼠标模式的 vim/tmux 等程序中，按住 Shift 拖动选择文本。

推荐通过 HTTPS 使用剪贴板。读取权限被浏览器拒绝时会提供手动粘贴框，可用 `Ctrl+V` / `⌘V` 贴入后发送。粘贴直接交给 xterm 处理并保留 bracketed-paste，不再确认多行、控制字符或较长文本；目标程序不支持该模式时，多行内容可能立即执行。单次粘贴保留 1 MiB 大小限制。复制操作不将选区内容写入调试日志。

## Agent 工作台

打开 **AI 助手 → API 设置**，配置兼容 Chat Completions 的 API 基础地址和密钥。基础地址按服务商要求包含 `/v1`，不要包含 `/chat/completions`。支持 HTTP/HTTPS、自定义端口、内网 IP 和 Docker 服务名；HTTP 仅应在可信网络使用。Docker 内的 `127.0.0.1` 指 backend 容器自身；访问宿主机 CPA 可填 `http://宿主机IP:映射端口/v1`，同网络容器可填 `http://cpa:8317/v1`。密钥加密保存，更换地址须重新提供密钥，无需新增 `.env` 变量。

工作台由任务列表、对话/执行时间线和底部控制栏组成；也可点击顶栏 AI 按钮，在 SSH 终端右侧并排使用并拖动宽度。任务由后端驱动，切换页面、关闭面板或刷新不会停止任务。任务历史自动脱敏后加密保存，可查看、导出或删除。未发送的草稿只保留在页面内存。旧版保存的会话可附加为上下文，不会直接执行旧建议。

### 终端内随时呼出

终端标签栏的 **AI** 按钮在专注模式下也始终可见。按 `Ctrl+I`（macOS 为 `⌘I`）打开/关闭侧栏；在侧栏按 `Esc` 返回终端。关闭侧栏不停止任务，也不丢失对话。此快捷键在工作区内保留给 Agent，不再向 SSH 发送 Ctrl+I；需要 Tab 时直接使用 Tab 键。

从终端呼出时，优先附加当前选区，无选区则附加最近 120 行，并为新任务选择当前服务器。这些内容先进入本地草稿，确认发送前不会上传给模型；仍可预览脱敏内容。已有任务或草稿与当前终端不同时，侧栏显示“在此服务器新建任务”，不会自动改变已有任务的执行范围。上方始终显示实际执行服务器。

同一服务器重复打开侧栏会恢复原有对话和草稿，不覆盖日志；需要更新上下文时，点击“附加终端输出 → 最近输出 / 选中文本”。

可以直接描述“检查磁盘占用”“读取 /etc/nginx/nginx.conf，修改指定配置并验证”等任务，Agent 会经独立 SSH 通道读取、执行、修改并复查结果。默认每轮批准，也可明确授权本次任务自动推进。它不操作人工终端的按键，不继承人工 shell 的当前目录、sudo 状态或环境变量；请提供绝对路径。文件修改以审批卡中的 SSH 命令为准，不是 IDE 式逐行差异编辑器，也不提供自动回滚。

### 模型与思考等级

模型列表从服务商 `/models` 自动读取并提供下拉选择；默认选择仅依据名称启发式，不代表性能、价格或兼容性排名。不支持列表接口时可在“执行限制”中手动填写模型 ID。每个任务保存独立的模型与参数，后续改变新任务的选项不影响已有任务。

思考等级支持服务商默认、关闭、最低、低、中、高、极高和最高；默认不发送额外参数，其余通过 `reasoning_effort` 传递。并非每个模型/服务商支持所有等级，不兼容时显示原始 API 错误，不会静默换模型或降低等级。可使用“测试连接”检查已保存的 API。任务暂停、等待审批或完成后，可在底栏切换模型、思考等级和审批方式；旧审批随之作废，发送下一条要求后重新规划。切换到自动模式仍需明确授权。

### 三种审批方式

| 方式 | 行为 |
| --- | --- |
| 仅讨论分析 | 讨论任务、分析日志与监控，不执行 SSH 命令。 |
| 每轮批准（默认） | 展示具体目标、命令和用途，勾选批准后执行该轮；返回结果后继续分析，下一轮重新批准。 |
| 授权本次任务 | 额外明确授权后，在选定目标及执行限制内自动执行、读取结果并继续，直到完成或达到上限。可能产生破坏性操作，建议先用最小权限账号测试。 |

使用流程：

1. 在“服务器与上下文”中选择 SSH 目标。名称/别名识别仅协助选择，必须由你确认范围；清单和监控数据不会自动授予其他服务器执行权限。
2. 输入任务，选择模型、思考等级、审批方式与执行限制；可附加选中的终端文本、最近输出或手动日志，可选提供设备别名清单和哪吒快照。终端历史不会被自动上传。
3. 通过“预览脱敏内容”检查发送范围；确认发送，自动模式还须单独勾选本次任务执行授权。之后的消息和结果复查沿用此任务的服务商与上下文授权。
4. 每轮批准模式下，检查审批卡上的服务器与命令。不同服务器可执行不同命令组。需要临时密码的连接会暂停等待输入，临时凭据仅在后端内存使用本轮，绝不发送给模型、不保存在任务里；自动模式的下一轮也须重新输入并批准。
5. 时间线显示计划、命令、逐服务器输出/错误/退出码与后续分析。后端直接读取真实 SSH 执行结果，不信任浏览器提供的替代输出。可发送补充要求，拒绝当前未执行方案；运行期间先暂停或停止再讨论。

可调整并行数 1–20（默认 5）、每组脚本超时 10–1800 秒（默认 120）、最多 1–30 轮（默认 10）。最多选择 50 台，每轮合计最多 8 条命令；每个用户最多 5 个未结束任务、100 条历史。任务一次授权有效 1 小时；达到轮数上限后不再执行新命令。每个目标的长输出独立截断并标记，模型请求最长等待 3 分钟，执行状态约每 1.5 秒刷新。新工作台显示完成后的模型答复，不展示模型隐藏思考过程。

“暂停”会等当前命令组结束后停止自动推进；“停止任务”请求取消当前 SSH 任务并阻止启动后续命令。**停止不会回滚已发生的修改，也无法保证终止远端脱离 SSH 的后台进程。** 后端重启将运行中任务标记为中断，不自动继续执行；审批前还会校验连接、密钥、代理及 API 配置是否改变。重启或过期后应检查结果，再复制为新任务。

复用已有 SSH 密码、密钥和代理配置，无需在目标机安装探针。命令在新的 SSH 执行通道运行，不继承交互终端的目录和环境，跨轮操作应使用绝对路径。自动脱敏会遮盖常见密码/Token/API Key 字段、Authorization/Cookie、URL 凭据、私钥/证书块与已保存凭据的已知值，**不能保证识别任意业务秘密**。发送前仍需人工检查，API 服务商的数据保留政策同样适用。详细安全边界见 [SECURITY.md](./SECURITY.md)。


## 哪吒监控与设备别名

1. 打开“监控探针”，填写公开哪吒面板地址，例如 `https://tz.xmray.de`，保存即可。无需账号、密码或 API Key；使用 `/api/v1/ws/server` 公开实时接口，不支持强制登录的面板。仅允许公网 HTTPS 443，页面可见时每 5 秒刷新。
2. 将监控节点显式绑定到 FleetDeck 设备；不会按相似名称自动绑定。页面显示 CPU、内存、磁盘、负载、网络速率、数据时间及过期状态。更换面板地址会清除旧绑定。
3. 在同一页给设备设置别名，例如 `1号服务器`。在 Agent 中输入“1号服务器执行 xxx”，点击“识别消息中提到的设备”并确认执行范围；名称重名时手动选择。
4. 点击“与 Agent 讨论”，或在 Agent 中勾选设备清单、监控快照。数据会进入脱敏预览，确认后才发给模型。监控备注等任意网页内容不采集；旧上报时间不是当前健康状态的证明。监控数据只用于分析，不能自动授权执行。

## 自动化剧本（执行包）

剧本是预先保存的执行包。一个剧本可以包含多条顺序命令、文件附件、变量和失败策略，并可应用于单台、分组或任意选择的服务器。运行时会生成独立任务，记录逐主机日志与最终状态，适合安装软件、基线配置、巡检和批量更新。

## 架构

```text
Browser
  └─ Frontend (Vue 3 + Vite + Nginx)
       ├─ Backend API/WebSocket (Express 5 + SQLite)
       │    ├─ SSH/SFTP/批量任务/剧本
       │    └─ 加密凭据与审计数据
       └─ Remote Gateway (private service auth)
            └─ guacd ── RDP/VNC
```

只有前端端口发布到宿主机。Backend、Remote Gateway 和 guacd 只在 Compose 网络内通信。

## 数据与升级

- 持久数据位于 `./data`，运行密钥位于 `./secrets`；两者均被 Git 忽略。
- 从旧版本启动时，`nexus-terminal.db` 会自动迁移为 `fleetdeck.db`，数据库内容不会重建。
- 必须同时备份 `data` 和 `secrets/encryption_key`。丢失主加密密钥后，保存的凭据无法恢复。
